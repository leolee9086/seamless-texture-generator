# 水印预设保存失效修复

## 📋 问题概述

**现象**：水印模块无法保存预设，点击界面上的保存按钮没有反应

**错误信息**：
```
DataCloneError: Failed to execute 'put' on 'IDBObjectStore': #<Object> could not be cloned.
```

---

## 🔍 问题分析

### 代码流程追踪
```
用户点击保存按钮
    ↓
WatermarkPresetManager.vue: handleSave()
    ↓ emit('save', presetName)
WatermarkSettings.vue: 保存(name)
    ↓ 保存当前配置(props.config, name)
WatermarkSettings.ctx.ts: 保存当前配置()
    ↓ 创建预设对象 { id, 名称, 配置: {...配置}, 创建时间 }
    ↓ 保存预设(新预设)
watermark.indexedDB.ctx.ts: 保存预设()
    ↓ fs.write(`presets/${预设.id}`, 预设)
IndexDBFS.class.ts: write()
    ↓ IDBObjectStore.put(data) ← 💥 错误发生点
```

### 根本原因
在 [`WatermarkSettings.ctx.ts`](demo/src/components/control-panels/watermark/WatermarkSettings.ctx.ts) 中：
```typescript
配置: { ...配置 },  // 浅拷贝无法处理 Vue 响应式代理对象
```

`props.config` 是 **Vue 响应式代理对象 (Proxy)**，浅拷贝只复制顶层属性，嵌套对象仍是 Proxy。IndexedDB 的结构化克隆算法**无法克隆 Proxy 对象**。
